# Natalia Dantas - Marketing Digital

Website institucional e landing page da **Natalia Dantas Marketing Digital**.

## 🚀 Sobre o Projeto

Landing page moderna de alta conversão para agência de marketing digital focada em tráfego pago (Meta Ads, Google Ads) e gestão estratégica de mídias sociais para PMEs na Espanha e América Latina.

- **Stack**: HTML5, React 19, Tailwind CSS, Lucide Icons, Framer Motion (compilados em página única para máxima velocidade e performance estática sem necessidade de etapa de build).
- **Responsivo**: Adaptado para mobile, tablet e desktop.
- **Integração**: WhatsApp integrado com mensagens personalizadas para cada serviço e plano.

## 📁 Estrutura de Arquivos

- `index.html`: Código completo da página (estrutura, estilos, animações e lógica).
- `content.json`: Dados e textos editáveis do site (serviços, depoimentos, planos, FAQ e contatos).
- `vercel.json`: Configuração de rotas limpas para hospedagem na Vercel (`cleanUrls: true`).

## 🌐 Publicação (Deploy)

### Opção 1: Vercel (Recomendado)
1. Acesse [vercel.com](https://vercel.com) e conecte sua conta do GitHub.
2. Clique em **Add New > Project** e importe este repositório.
3. Em **Framework Preset**, selecione **Other**.
4. Não é necessário comando de build ou configuração adicional. Clique em **Deploy**.

### Opção 2: GitHub Pages
1. No repositório no GitHub, vá em **Settings > Pages**.
2. Em **Source**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
